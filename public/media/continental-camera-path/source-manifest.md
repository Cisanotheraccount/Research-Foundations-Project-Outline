# Continental Rooftop interactive camera path

- Gaussian reconstruction and source capture: Ci Song, Continental Rooftop, 2026.
- Interactive renderer: Three.js + Spark.
- Scene: `assets/scene.ply` (137,722 Gaussians).
- Camera data: `assets/transforms.json` (1,481 reconstructed SfM camera poses).
- Website behavior: the camera-path animation starts automatically when page 04 becomes active; dragging orbits the overview camera and scrolling zooms it.
