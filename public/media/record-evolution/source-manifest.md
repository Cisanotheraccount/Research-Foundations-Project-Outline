# Record Evolution media

- `s04-*`, `s05-*`, `s06-*`: real frames and derived stereo demonstration from Charlotte May, “Video of a Living Room,” Pexels.
- `inria-3dgs-playroom.mp4` and `s07-*`: official Inria GraphDeco 3D Gaussian Splatting playroom result, SIGGRAPH 2023. Frames are mechanically extracted from the same orbit video and are not generatively redrawn.
- `continental-rooftop-capture-loop.mp4`: user-provided 4K source footage from the Continental Rooftop capture session, recorded August 3, 2026. The web version uses the visually stable 61–71 second interval, resized to 1600×900, lightly normalized for contrast and saturation, and arranged as a forward–reverse loop so playback has no hard jump. Audio is removed. The 20-second H.264 web file is approximately 13 MB; the 522 MB original `.mov` remains unchanged in Google Drive.
- `continental-rooftop-capture-poster.jpg`: mechanically extracted from the same source at 66 seconds and processed with the same restrained color normalization. This is capture footage, not a trained Gaussian reconstruction.
- `continental-rooftop-view-01.jpg`, `continental-rooftop-view-02.jpg`, and `continental-rooftop-view-03.jpg`: full-HD stills mechanically extracted from the same user-provided source at 62, 66, and 70 seconds. They replace the former Inria playroom thumbnails and show three successive positions along the real Continental Rooftop capture path. They are capture evidence, not novel reconstructed viewpoints.
- `cvpr2024-4dgs-standup-time.mp4` and `s09-time-*`: official “4D Gaussian Splatting for Real-Time Dynamic Scene Rendering” result, CVPR 2024, CC BY-SA 4.0. Frames are mechanically extracted and are not generatively redrawn.
- `s09-interstellar-tesseract.jpg`: classroom-only film still from *Interstellar* (2014), Paramount Pictures / Warner Bros. Pictures, used as a visual metaphor and not as technical evidence.

The WebGL Gaussian field in the opening is a code-native explanatory visualization. It uses anisotropic, rotated, colored, translucent Gaussian billboards and is not presented as a trained reconstruction.
